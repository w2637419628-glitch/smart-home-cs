# 体验站部署 · 让别人点开链接就能玩

> 和"正式交付"不同：这里是**公开链接、随便点、看完就走**。
> 所以重点不是权限，而是 **别烧钱、别崩、别被玩坏**。

---

## 一、和交付版的三个区别

| | 交付版（给客户用） | **体验站（给人点开看）** |
|---|---|---|
| 访问控制 | 账号密码、按人分配 | **不要密码**，点开就玩 |
| 防滥用 | 权限体系 | **每日额度**（单 IP + 全站） |
| 数据 | 客户真实数据 | 演示数据，坏了就重置 |

---

## 二、三条路线，按"多快能给别人一个链接"排

| 路线 | 时间 | 成本 | 国内访问 | 适合 |
|---|---|---|---|---|
| **A. 内网穿透**（cpolar / ngrok） | **10 分钟** | 免费~20 元/月 | 一般 | 先给人看一眼，验证效果 |
| **B. 国内轻量服务器** | 30 分钟 | 60~90 元/月 | **快** | 正式发给客户/面试官 |
| **C. 免费托管平台**（Railway/Render/Zeabur） | 20 分钟 | 免费额度 | 慢/需梯子 | 受众有梯子、想零成本 |

**建议顺序**：先用 A 发给 1-2 个人看反应 → 有人真感兴趣再用 B。

---

## 三、必须打开「体验模式」（否则会被刷爆）

改 `.env`：

```ini
DEMO_MODE=true
DEMO_PER_IP_DAILY=30      # 每个 IP 每天 30 次对话
DEMO_GLOBAL_DAILY=800     # 全站每天 800 次
```

效果：

- 同一个 IP 超过 30 次 → 回复“今天的体验次数用完了，明天重置”
- 全站超过 800 次 → 所有人都会被挡，保护你的余额
- 顶部会显示「今日全站剩余 N 次」

> 按 DeepSeek 的价格，一次对话约 2~3 次模型调用，800 次对话大约 **几块钱**。

## 四、路线 A：内网穿透（最快）

适合：只给 1-2 个人看，或者自己远程演示。

```powershell
# 1) 本机先跑起来
python start.py

# 2) 另开一个窗口，用 cpolar（国内快）
cpolar http 8100
#   或 ngrok
ngrok http 8100
```

它会给你一个公网地址，比如 `https://xxxx.cpolar.top`，直接发出去。

⚠️ 电脑关机 / 断网就失效，只适合临时演示。

---

## 五、路线 B：国内轻量服务器（推荐）

### 买

- 阿里云 / 腾讯云「轻量应用服务器」
- **2 核 2G / 40G / Ubuntu 22.04**
- **不用买域名、不用备案** —— 用 `http://IP:8080` 直接访问

### 部署（Docker，5 条命令）

```bash
# 传代码
scp -r "D:\桌面\会进化的智能家居客服" root@你的IP:/opt/smart-home-cs

# 装 Docker
curl -fsSL https://get.docker.com | sh

# 改配置：打开体验模式
cd /opt/smart-home-cs
nano .env      # DEMO_MODE=true，填 LLM_API_KEY

# 起服务（对外暴露 8080）
cd deploy
# 把 docker-compose.yml 里的 "127.0.0.1:8100:8100" 改成 "8080:8100"
docker compose up -d --build
```

访问 `http://你的IP:8080` 就能用了，**不需要 nginx、不需要密码**。

> 想加域名和 HTTPS 再回头看 `部署指南.md` 的第四、六节。

## 六、路线 C：免费托管平台

以 Railway / Render 为例：

1. 先把代码推到 GitHub（仓库已准备好）
2. 平台里 New Project → Deploy from GitHub repo → 选 `smart-home-cs`
3. 在平台的环境变量里填：

```
LLM_PROVIDER=openai
LLM_BASE_URL=https://api.deepseek.com/v1
LLM_API_KEY=sk-你的演示专用key
LLM_MODEL=deepseek-chat
DEMO_MODE=true
DEMO_PER_IP_DAILY=20
DEMO_GLOBAL_DAILY=300
PORT=8100
```

4. 平台会自动给一个 `https://xxx.up.railway.app` 的链接

⚠️ 两个坑：
- 免费实例会**休眠**，第一次打开要等 30 秒
- 容器文件系统是临时的，`data.db` 重启就没了 → 正好，等于自动重置

## 七、上线前检查清单

- [ ] `.env` 里 `DEMO_MODE=true`（**最容易忘，忘了就是敞开了烧钱**）
- [ ] 用的是**演示专用 Key**，不是你自己开发用的那个
- [ ] DeepSeek 控制台设了**余额告警**
- [ ] 试一下：连续发 35 次，看会不会被拦
- [ ] 发给别人前，自己先用手机（不同网络）打开一次，确认能访问
- [ ] 知道怎么清空数据：`bash deploy/reset-demo.sh`

---

## 八、演示期间怎么维护

| 情况 | 处理 |
|---|---|
| 数据被访客教乱了 | `bash deploy/reset-demo.sh` 恢复出厂 |
| 有人恶意刷 | 把 `DEMO_PER_IP_DAILY` 调到 5，或临时 `DEMO_MODE=true` + 更低额度 |
| 额度总被很快用完 | 说明真有人玩，考虑换成真实交付版（加账号） |
| 模型连不上 | 检查服务器能否访问 `api.deepseek.com`；系统现在会优雅提示，不会 500 |

---

## 九、一句话总结

> 体验站 = **公开 + 限流 + 小额 Key + 随时重置**。
> 不用做权限，但一定要做额度；不用买域名，但一定自己先用手机试一遍。
