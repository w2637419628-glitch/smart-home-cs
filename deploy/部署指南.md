# 部署指南 · 把演示放到公网给别人用

> 目标：让 3~10 个人可以通过链接打开这个系统试用（含真人教学、审核、看轨迹）。
> 预计成本：**每月 60~100 元**（服务器）+ 模型 API 用量（几块钱）。

---

## 〇、先想清楚三件事

| 问题 | 为什么重要 |
|---|---|
| **给谁用？** | 公开演示 → 必须加密码 + 限流；只给 3 个朋友 → 密码够了 |
| **谁付 API 费？** | 每次对话都花你的 DeepSeek 余额。**公开场合不加限流 = 一天烧光** |
| **要不要留痕？** | 演示库是共享的，别人教的东西所有人都看得见（这既是缺点也是卖点） |

---

## 一、买什么服务器

### 推荐配置

| 项 | 建议 | 说明 |
|---|---|---|
| 规格 | **2 核 2G / 40G 系统盘** | 模型计算在外部 API，服务器只跑 Python，1核1G 也行但别省 |
| 系统 | **Ubuntu 22.04 / 24.04 LTS** | Docker 和 nginx 生态最顺 |
| 带宽 | 3~5 Mbps 峰值 | 纯文本页面，够 10 人同时用 |
| 地区 | 国内（阿里云/腾讯云轻量）或香港 | 国内便宜但 80/443 要备案，见下 |

### 价格参考（2026 年，新用户首年更低）

| 厂商 | 产品 | 大致价格 |
|---|---|---|
| 阿里云 | 轻量应用服务器 2C2G | ¥60~90 / 月 |
| 腾讯云 | 轻量 2C2G | ¥50~80 / 月 |
| 雨云 / 其他小厂 | 2C2G | ¥30~50 / 月（稳定性和备案支持弱一些） |

### ⚠️ 关于备案（国内服务器）

- 用 **80 / 443 端口 + 域名** → 通常需要 ICP 备案（7~20 天）
- 用 **非标端口（如 8080、8443）或直接 IP 访问** → 一般不需要备案
- 想省事：**先直接用 `http://服务器IP:8080` 给别人用**，不买域名、不备案
- 这条政策各厂商执行细节不同，**下单前问一句客服**最稳

## 二、把代码传上去

在你自己的 Windows 上：

```powershell
# 假设服务器 IP 是 1.2.3.4，用 root 或 ubuntu 用户
scp -r "D:\桌面\会进化的智能家居客服" root@1.2.3.4:/opt/smart-home-cs
```

或者用 WinSCP / 宝塔面板 拖上去。

> **不要**把 `.env` 里带真实 Key 的版本到处传。传完立刻在服务器上确认：

```bash
cd /opt/smart-home-cs
ls -la .env          # 确认存在
nano .env            # 检查 LLM_PROVIDER / LLM_API_KEY
```

## 三、装起来（两种方式，选一种）

### ⚡ 最快路径：一个脚本搞定

```bash
cd /opt/smart-home-cs
cp .env.example .env && nano .env      # 填 LLM_API_KEY
bash deploy/setup-server.sh            # 装 Docker + 构建 + 启动 + 自检
```

脚本会自动：检查依赖 → 打开体验模式（DEMO_MODE=true）→ 装 Docker → 构建启动 → 本机自测 → 打印对外地址。

> 只做体验站的话，看到「本机自测通过 ✅」就结束了，**不用再配 nginx**。
> 下面两种方式适合需要密码/HTTPS 的正式交付。

### 方式 A：Docker（推荐，最省心）

```bash
# 1) 装 Docker（一行）
curl -fsSL https://get.docker.com | sh

# 2) 起服务
cd /opt/smart-home-cs/deploy
docker compose up -d --build

# 3) 看状态
docker compose ps
docker compose logs -f --tail=50
```

起来后**只在服务器本机**能访问 `127.0.0.1:8100`，对外要靠 nginx（下一步）。

### 方式 B：裸机 + systemd（不装 Docker）

```bash
cd /opt/smart-home-cs

# 1) 建虚拟环境装依赖
python3 -m venv .venv
.venv/bin/pip install -r requirements.txt

# 2) 建数据目录
mkdir -p data && chown -R www-data:www-data /opt/smart-home-cs

# 3) 装成系统服务
sudo cp deploy/smart-home-cs.service /etc/systemd/system/
sudo systemctl daemon-reload
sudo systemctl enable --now smart-home-cs

# 4) 看日志
sudo journalctl -u smart-home-cs -f
```

## 四、加密码（必做）

```bash
sudo apt update && sudo apt install -y nginx apache2-utils

# 建账号：用户名 demo，然后按提示输两次密码
sudo htpasswd -c /etc/nginx/.htpasswd demo

# 装反代配置
sudo cp /opt/smart-home-cs/deploy/nginx-demo.conf /etc/nginx/conf.d/

# 如果打算用 8080 对外开放，把配置里的 listen 80 改成 8080
sudo nano /etc/nginx/conf.d/nginx-demo.conf

sudo nginx -t && sudo systemctl reload nginx
```

现在访问 `http://服务器IP`（或 `:8080`）会先弹登录框。

> **给多个人用**：`sudo htpasswd /etc/nginx/.htpasswd 张三`（去掉 `-c`，否则会覆盖文件）

## 五、限流（必做，保护你的 API 余额）

`nginx-demo.conf` 里已经写了：

```nginx
limit_req_zone $binary_remote_addr zone=demo:10m rate=30r/m;
limit_req zone=demo burst=10 nodelay;
```

含义：每个 IP 每分钟最多 30 次请求，超了返回 429。

按 30 次/分钟估算，一个人狂点也就 30 次；10 个人同时用最多 300 次/分钟。
一次对话大约 2~3 次模型调用，按 DeepSeek 价格，**一小时最坏也就几块钱**。

## 六、要不要域名 + HTTPS（可选）

```bash
# 有域名并解析到服务器后
sudo apt install -y certbot python3-certbot-nginx
sudo certbot --nginx -d demo.你的域名.com
```

证书自动续期，不用管。没域名就用 `http://IP:8080`，演示够用。

## 七、控制花费（最容易翻车的地方）

**这是最容易出事的环节**，按顺序做三件事：

1. **在 DeepSeek 控制台设"余额告警"**（比如余额低于 20 元发短信）
2. **单独申请一个演示专用的 Key**，不要复用你自己开发用的
3. 想更稳：把 `.env` 改成
   ```ini
   LLM_PROVIDER=mock
   ```
   断网也能演示，**完全零成本**，只是话术会变得像模板。适合"只给对方看流程"的场合。

> 备用方案：给 `LLM_MODEL` 换成更便宜的模型做演示，效果打折但成本降一个量级。

## 九、安全检查清单（上线前逐条打勾）

- [ ] nginx 加了 `auth_basic`，未登录看不到任何页面
- [ ] 应用只监听 `127.0.0.1:8100`，**没有**直接 `0.0.0.0:8100` 暴露公网
- [ ] 限流生效（`curl` 连打 40 次，应该出现 429）
- [ ] DeepSeek 余额告警已设
- [ ] `.env` 权限收紧：`chmod 600 /opt/smart-home-cs/.env`
- [ ] `/etc/nginx/conf.d/*.conf` 里没有把 `.env` 之类的文件暴露成静态资源
- [ ] 服务器防火墙只开 22 / 80 / 443（或 8080）
- [ ] 知道怎么一键重置演示数据

## 十、常见故障

| 现象 | 原因 | 处理 |
|---|---|---|
| 502 Bad Gateway | 应用没起来 | `docker compose logs` 看报错；多半是 `.env` 缺 Key |
| 页面能开但对话 500 | 模型调用失败 | 看日志里的 `MISSING_CREDENTIAL` / `401`；确认 Key 和余额 |
| 一直 429 | 限流触发 | 调 `rate=30r/m` 到 `60r/m`，或让访问者换网络 |
| 登录框反复弹 | `.htpasswd` 路径不对 | `sudo nginx -t` 会提示 |
| 数据被访客教乱了 | 演示库是共享的 | `bash deploy/reset-demo.sh` 重置 |
| 中文乱码 | 系统 locale | `export LANG=C.UTF-8`，Docker 镜像已内置 |

## 十一、一句话方案（懒人版）

如果只想**今晚就能给别人看**：

```bash
# 服务器上，3 条命令
curl -fsSL https://get.docker.com | sh
cd /opt/smart-home-cs/deploy && docker compose up -d --build
# 然后用 ssh 隧道临时给别人：ssh -L 8100:127.0.0.1:8100 root@1.2.3.4
```

比开公网还安全，适合只给 1~2 个人看。
